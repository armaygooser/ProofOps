# 决赛录屏脚本（约 55 秒）

## 录屏前

1. 打开 Element Web 的 ProofOps Team 房间。
2. 在房间中准备带 **打开证控中枢** 链接的任务消息。
3. 运行 `docker compose up --build`，浏览器准备 1920×1080。
4. 打开控制台后点击右上角 **重置**。

## 镜头与解说

### 0–6 秒：从 AgentTeams 进入

在 Element 房间展示任务与七角色协作，点击 **打开证控中枢**。

解说：`这是从 AgentTeams Element 房间打开的 ProofOps 证控中枢。`

### 6–22 秒：七智能体调查

点击 **一键演示至审批**。画面依次点亮七个 Agent、权限标签和证据盾牌。

解说：`七个最小权限智能体并行分工，过去需要多人逐项核查的遥测、设备、负荷和策略，现在由一个总管监督。`

### 22–33 秒：人类审批

镜头移到右侧审批舱，展示 L2 风险、目标、证据包哈希和提案哈希。点击 **人类批准提案**，勾选确认并批准。

解说：`智能体没有最终处置权。人类批准的是目标、参数和证据都已固定的精确提案。`

### 33–44 秒：执行与独立复测

点击 **执行已批准动作**，再点 **启动独立复测**。中央温度变绿，三项契约打勾。

解说：`受控执行器只接受未过期的哈希绑定审批。另一个独立角色重新观测温度、功率和心跳，不能由执行者自证成功。`

### 44–55 秒：证据链与回滚

指向底部独立证据摘要与 HMAC 操作链，点击 **回滚到安全状态** 并确认。

解说：`证据摘要和操作审计链分别保真。每一步都可追溯，回滚后旧复测结论立即失效。CyberGuard 的可信决策基座由此迁移到了工业中控。`

## 录屏注意

- 不出现“真实 PLC 已接入”“生产部署完成”等文字。
- 不把确定性轨迹称为真实模型调用。
- 页面保留 `隔离数字孪生` 与 `未连接真实 PLC / BMS` 标识。
