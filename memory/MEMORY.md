# ProofOps Long-Term Memory

## Product identity

- Name: ProofOps · 证控中枢
- Positioning: 面向工业操作的可信智能体决策系统
- Relationship: Independent product powered by the CyberGuard governance core.

## Durable decisions

- UI uses React, TypeScript, Vite, and Ant Design.
- The demo is a deterministic industrial digital twin; it never controls real equipment.
- Agent investigation is separate from human approval authority.
- Evidence hashes and the HMAC-linked action audit chain are displayed as separate concepts.
- AgentTeams integration targets Element Web through service publishing and Matrix room links.
